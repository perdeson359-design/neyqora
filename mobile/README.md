# NEYQORA Mobile

Capacitor tabanlı Android/iOS uygulama kabuğu.

- App ID: `com.neyqora.assistant`
- Production URL: `https://neyqora.kosseofficial.workers.dev`
- `NEYQORA_APP_URL` ile hedef URL değiştirilebilir.
- Android debug APK CI artifact olarak üretilir.
- iOS Simulator build CI üzerinde imzasız doğrulanır.
- Native App, Haptics, Share ve Status Bar pluginleri projeye dahildir.

Mağaza imzalama/sertifika bilgileri repoya konmaz; release aşamasında GitHub Secrets kullanılır.
